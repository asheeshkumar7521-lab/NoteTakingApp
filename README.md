# 📝 Note Taking App

A beginner-friendly **Note Taking App** project built using HTML and CSS to practice frontend web development.

## 📌 About the Project

The Note Taking App is a simple web project focused on creating a clean and user-friendly interface for taking notes. It demonstrates the use of HTML for webpage structure and CSS for styling.

## ✨ Features

- 📝 Simple and clean user interface
- 🎨 CSS-based styling
- 💻 Lightweight frontend project
- 🌐 Runs directly in a web browser
- 🚀 Beginner-friendly project structure

## 🛠️ Technologies Used

- **HTML5** – Creates the webpage structure
- **CSS3** – Adds styling and layout

## 📂 Project Structure

```text
NoteTakingApp/
├── index.html
├── style.css
└── README.md
```

## 🚀 Getting Started

Follow these steps to run the project locally.

### Step 1: Clone the Repository

```bash
git clone https://github.com/asheeshkumar7521-lab/NoteTakingApp.git
```

### Step 2: Open the Project Folder

```bash
cd NoteTakingApp
```

### Step 3: Run the Application

Open `index.html` in your preferred web browser.

Alternatively, open the project in Visual Studio Code and use the Live Server extension.
